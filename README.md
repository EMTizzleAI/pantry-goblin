# Pantry Goblin 🥫👹

A location-aware food-resource finder from EMTizzleAI, descended from the original Google Sheets + Apps Script daily-report Goblin.

## V1
- Search by city, ZIP, address, or device location
- Queries OpenStreetMap/Overpass for mapped food-bank resources near the user
- Phone, website, and directions when published
- Never claims unpublished hours are verified
- Installable PWA shell for Android
- Excessive bean lore

This is an early public-resource discovery tool. Listings can be incomplete or stale; verify hours and eligibility before traveling.

## Lineage
The original Pantry Goblin read a `Pantries` Google Sheet, filtered entries by weekday, and emailed a daily report. V1 moves discovery to the phone while preserving the same practical mission.
